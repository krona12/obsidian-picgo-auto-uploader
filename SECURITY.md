# Security Policy

## Supported versions

The latest `0.1.x` release receives security fixes. Pre-release builds and older minor lines are unsupported.

## Report a vulnerability privately

Use the repository's [private security advisory form](https://github.com/krona12/obsidian-picgo-auto-uploader/security/advisories/new). Do not open a public issue for a suspected vulnerability.

Include the plugin, Obsidian, Windows, PicGo, and provider versions; clear reproduction steps; expected and actual behavior; and a sanitized diagnostic export when useful. State whether the source attachment still exists and whether a backup is available.

Never send real secrets, image contents, Vault contents, note text, or absolute private paths. Replace identifying names and paths with synthetic examples, remove authorization values, and inspect exported diagnostics before attaching them.

For ordinary bugs without security impact, use the public bug-report form.
